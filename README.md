# AdsClipper

**AdsClipper** — настольное приложение для автоматизированной обработки вертикального видеоконтента, поиска клипов и публикации роликов на YouTube, Instagram и TikTok.

Программа объединяет в одном интерфейсе подготовку видео, оформление, публикацию, восстановление загрузок и просмотр статистики.

# Возможности

### 🎬 Автоматическое создание клипов

AdsClipper предназначен для работы с длинными видео, в том числе Twitch/VOD-записями.

Программа может:

- анализировать исходное видео;
- искать интересные моменты;
- выбирать лучшие непересекающиеся фрагменты;
- автоматически формировать вертикальные ролики;
- сохранять готовые клипы в отдельную папку;
- обрабатывать несколько клипов параллельно.

---

### 📱 Вертикальный формат

Основной формат программы — вертикальный контент **9:16**.

Поддерживаются пресеты:

- 1080×1920;
- 720×1280;
- 1440×2560;
- 2160×3840;
- пользовательское разрешение.

Вертикальная композиция рассчитана на современные форматы Shorts, Reels и TikTok.

---

### 🎮 Игровая область + веб-камера

Для роликов можно отдельно настроить:

- область игрового видео;
- область веб-камеры;
- положение веб-камеры;
- масштабирование;
- способ вписывания изображения.

В интерфейсе предусмотрен визуальный preview, поэтому положение элементов можно подобрать до запуска рендера.

---

### ⚡ Параллельный рендер

AdsClipper умеет обрабатывать несколько клипов одновременно.

Количество параллельных задач можно выбрать вручную или оставить режим **«Авто»**.

Автоматический режим учитывает доступные ресурсы системы, в том числе видеопамять при использовании GPU.

# Работа с видео

## Добавление исходного файла

Выберите исходный Twitch/VOD или другой совместимый видеофайл в интерфейсе программы.

Для удобства предусмотрена работа с перетаскиванием файлов.

---

## Поиск клипов

Параметры поиска позволяют настроить:

- количество клипов;
- длительность;
- шаг анализа;
- параметры исходного материала.

AdsClipper старается выбирать моменты без пересечений, чтобы несколько готовых роликов не содержали один и тот же фрагмент.

---

# Реклама

AdsClipper поддерживает добавление рекламного ролика в готовый клип.

Реклама располагается поверх стоп-кадра основного видео:

1. основной ролик доходит до рекламной точки;
2. основной кадр фиксируется;
3. поверх него показывается реклама;
4. после завершения рекламы видео продолжается с нужного места.

Положение рекламы можно настроить в preview.

Доступны параметры:

- X;
- Y;
- ширина;
- высота;
- длительность.

---

# Субтитры и оформление

AdsClipper поддерживает несколько вариантов оформления текста:

- **TikTok**;
- **MrBeast**;
- **Минималистичные**;
- **Слово-за-словом**.

Система учитывает распознанную речь и может синхронизировать текст с видео.

Для важных и эмоциональных слов предусмотрено отдельное визуальное выделение.

# YouTube

AdsClipper поддерживает публикацию готовых роликов на YouTube через OAuth.

## Поддерживается

- подключение YouTube-канала;
- несколько каналов;
- несколько OAuth JSON;
- выбор OAuth-профиля для конкретного канала;
- загрузка Shorts;
- автоматическая генерация названий;
- ключевые слова;
- хештеги;
- история публикаций;
- восстановление незавершённой загрузки;
- статистика опубликованных Shorts.

---

## Генерация названий

Для каждого ролика AdsClipper может создать отдельное название.

Настраиваются:

- основная фраза;
- ключевые слова;
- хештеги.

Перед публикацией можно посмотреть примеры сгенерированных названий.

Название ограничивается требованиями YouTube.

---

## Shorts

Ролики, опубликованные как Shorts через AdsClipper, сохраняются и отображаются как Shorts.

Ссылки на опубликованные ролики формируются в формате:

`youtube.com/shorts/VIDEO_ID`

---

# Instagram Reels

AdsClipper поддерживает публикацию вертикальных роликов в Instagram через официальный Meta Graph API.

## Возможности

- подключение Instagram Professional;
- публикация Reels;
- несколько подключений;
- автоматическая генерация названий;
- ключевые слова;
- хештеги;
- история публикаций;
- статистика Reels.

---

## Генерация названий Reels

Для Instagram используется отдельная система генерации названий, построенная по той же логике, что и YouTube.

Важно:

> В Instagram Reels нет отдельного поля `title`, как у YouTube.

Поэтому AdsClipper помещает сгенерированное название **первой строкой подписи (caption)**, а хештеги — ниже.

Пример:

```text
ЭТОТ МОМЕНТ НИКТО НЕ ОЖИДАЛ

#reels #gaming #twitch
```

# TikTok

AdsClipper поддерживает публикацию вертикальных роликов через **TikTok Content Posting API**.

Возможности:

- OAuth-подключение TikTok;
- загрузка вертикальных видео;
- выбор приватности;
- отображение состояния подключения;
- сохранение незавершённых сессий;
- восстановление загрузки после перезапуска;
- обработка ошибок API.

Для полноценной публикации возможности аккаунта и приложения TikTok должны соответствовать требованиям самого TikTok.

# Статистика

AdsClipper предоставляет отдельные разделы статистики для YouTube и Instagram.

## YouTube

Для опубликованных Shorts отображаются данные, получаемые через YouTube API.

В статистике можно видеть:

- название;
- дату публикации;
- просмотры;
- другие доступные показатели;
- ссылку на ролик.

Для удобства значения могут визуально различаться в зависимости от количества просмотров.

---

## Instagram Reels

Для Reels предусмотрен отдельный раздел статистики.

Он показывает:

- общую статистику;
- статистику отдельных роликов;
- количество просмотров;
- показатели вовлечённости;
- данные, доступные через Meta API.

Цветовая индикация помогает быстро определить наиболее успешные ролики.

# OAuth и подключение аккаунтов

AdsClipper не требует передачи пользователем пароля от YouTube или Instagram непосредственно в программу.

Подключение выполняется через OAuth:

1. пользователь нажимает подключение;
2. открывается браузер;
3. выполняется авторизация;
4. пользователь подтверждает необходимые разрешения;
5. AdsClipper получает разрешённый OAuth-доступ;
6. подключённый аккаунт появляется в программе.

---

## YouTube OAuth JSON

AdsClipper поддерживает несколько OAuth JSON.

Можно добавить несколько профилей, например:

```text
Основной
Резервный
Канал 2
Канал 3
```

После добавления JSON ему можно назначить понятное имя.

Затем для каждого YouTube-канала выбирается нужный OAuth-профиль.

### Важно

OAuth JSON и YouTube-канал — не одно и то же.

Один OAuth-профиль может использоваться для авторизации соответствующего аккаунта, а конкретный канал после авторизации сохраняется отдельно.

Если заменить OAuth JSON, ранее выданный refresh token другого OAuth-клиента автоматически не переносится. В таком случае канал необходимо подключить заново через нужный профиль.

---

# Управление YouTube-каналами

В AdsClipper можно удалять ранее подключённые YouTube-каналы.

Перед удалением программа запрашивает подтверждение.

При удалении:

- удаляется именно выбранный канал;
- другие каналы сохраняют свои OAuth-привязки;
- настройки остальных каналов не должны смешиваться;
- история роликов не переносится на другой канал;
- идентификаторы каналов остаются независимыми;
- освободившийся слот можно использовать повторно.

Это позволяет безопасно перестраивать список подключённых каналов без ручного редактирования JSON-файлов.

---

# Лимиты YouTube

YouTube может ограничивать количество загрузок на уровне самого канала.

Если API возвращает ошибку `uploadLimitExceeded`, AdsClipper показывает понятное уведомление вместо необработанного JSON-ответа API.

Важно понимать:

- это лимит YouTube;
- он не является лимитом OAuth JSON;
- добавление другого OAuth JSON не увеличивает лимит конкретного канала;
- точное время снятия лимита YouTube не передаёт приложению.

При достижении лимита следует дождаться восстановления возможности загрузки и повторить публикацию.

---

# Лицензия

AdsClipper может работать с системой лицензирования.

Лицензия проверяется через сервер лицензий и привязывается к устройству согласно настройкам системы лицензирования.

В приложении предусмотрена обработка ситуаций:

- недействительный ключ;
- повреждённая локальная лицензия;
- лицензия привязана к другому устройству;
- сервер временно недоступен;
- сервер не подтвердил лицензию.

---

# Автоматические обновления

AdsClipper поддерживает автоматическую проверку обновлений.

При запуске программа может проверить наличие новой версии.

Если обновление найдено:

1. AdsClipper получает информацию о новой версии;
2. скачивает установщик;
3. проверяет SHA-256;
4. закрывает текущую программу;
5. запускает установщик;
6. после успешного обновления снова запускает AdsClipper.

Проверка хеша необходима, чтобы программа не устанавливала повреждённый файл.

Пользователь также может вручную проверить наличие обновлений через соответствующий пункт интерфейса.

---

# FFmpeg и ускорение

FFmpeg используется для обработки и рендера видео.

В готовой Windows-сборке FFmpeg может поставляться вместе с AdsClipper, поэтому пользователю не требуется отдельно устанавливать FFmpeg в PATH.

Программа умеет искать встроенные версии:

- `ffmpeg.exe`;
- `ffprobe.exe`.

При необходимости используется системный FFmpeg.

---

## GPU

AdsClipper поддерживает обнаружение:

- NVIDIA;
- AMD Radeon.

При наличии подходящего оборудования программа может использовать аппаратное ускорение там, где оно доступно.

Для NVIDIA может использоваться NVENC/CUDA при наличии соответствующей поддержки FFmpeg и драйвера.

Если подходящее аппаратное ускорение недоступно, обработка может выполняться через CPU.

---

# Структура данных

Основные пользовательские данные хранятся отдельно от файлов самой программы.

В частности, данные YouTube находятся в пользовательской папке AdsClipper и включают OAuth-профили, токены, настройки каналов и историю.

Это важно для обновлений:

> Обновление программы не должно требовать повторного подключения всех каналов только из-за замены файлов приложения.

Не рекомендуется вручную изменять JSON-файлы AdsClipper без необходимости.

# Типичный сценарий работы

## 1. Подготовить исходное видео

Добавьте Twitch/VOD или другой исходный файл.

## 2. Настроить вертикальный формат

Выберите:

- разрешение;
- игровую область;
- веб-камеру;
- масштаб;
- качество.

## 3. Настроить оформление

При необходимости включите:

- субтитры;
- стиль текста;
- выделение важных слов;
- рекламу.

## 4. Создать клипы

Запустите поиск и рендер.

После обработки готовые ролики сохраняются в выбранной папке.

## 5. Подключить платформы

Подключите необходимые аккаунты:

- YouTube;
- Instagram;
- TikTok.

## 6. Настроить публикацию

Для YouTube и Instagram можно задать:

- основную фразу;
- ключевые слова;
- хештеги;
- параметры публикации.

## 7. Опубликовать

Выберите нужные ролики и запустите публикацию.

AdsClipper сохраняет состояние операции, чтобы минимизировать риск потери прогресса при ошибке или перезапуске.

## 8. Проверить статистику

После публикации можно открыть статистику YouTube или Instagram и посмотреть результаты роликов.

# Решение распространённых проблем

## «YouTube-канал не найден»

Проверьте:

- что в авторизованном Google-аккаунте действительно есть YouTube-канал;
- что используется правильный OAuth JSON;
- что подключение выполнено заново после замены OAuth-клиента.

---

## «YouTube достигнут лимит загрузок»

Это ограничение со стороны YouTube.

Смена OAuth JSON не сбрасывает лимит конкретного канала.

Подождите восстановления возможности загрузки и повторите публикацию.

---

## «Instagram Professional аккаунт не найден»

Instagram-подключение требует корректно настроенного профессионального Instagram-аккаунта и связанной инфраструктуры Meta.

Проверьте:

- что Instagram является Professional;
- что он связан с соответствующей Facebook Page;
- что авторизованный Facebook-аккаунт имеет необходимые права;
- что в Meta-приложении добавлены необходимые разрешения;
- что OAuth Redirect URI настроен точно.

---

## Ошибка Redirect URI

Redirect URI в настройках приложения должен полностью совпадать с URI, который использует AdsClipper.

Важно совпадение:

- `https://`;
- домена;
- пути;
- порта, если он используется;
- завершающего `/`, если он присутствует.

Даже небольшое отличие может привести к ошибке OAuth.

---

## Нет FFmpeg

В официальной Windows-сборке FFmpeg обычно поставляется вместе с AdsClipper.

Если программа всё равно сообщает об отсутствии FFmpeg, проверьте целостность установки и наличие:

```text
ffmpeg.exe
ffprobe.exe
```

в папке `_internal` установленного приложения.

---

## Нет звука после обработки

AdsClipper содержит отдельную диагностику аудиодорожки и проверку результата после рендера.

При проблеме рекомендуется посмотреть папку:

```text
logs
```

и найти актуальный файл:

```text
AdsClipper_debug_YYYYMMDD_HHMMSS.log
```

---

# Безопасность

Не передавайте другим людям:

- OAuth JSON с секретами;
- refresh token;
- client secret;
- ключи лицензии;
- GitHub Personal Access Token;
- другие приватные данные.

OAuth-файлы и токены должны храниться только у владельца соответствующего аккаунта.

---

# Важные замечания

AdsClipper использует официальные API платформ там, где это предусмотрено интеграцией.

Доступные функции зависят от:

- состояния аккаунта;
- разрешений;
- настроек приложения;
- требований соответствующей платформы;
- API-лимитов;
- статуса проверки приложения.

Некоторые возможности могут быть недоступны конкретному аккаунту даже при корректной настройке программы.
